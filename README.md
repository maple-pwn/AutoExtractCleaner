# AutoExtractCleaner - 压缩包自动清理工具

Windows 系统托盘工具，自动监控文件夹并在压缩包解压后删除原文件。

## 功能

- **系统托盘运行** - 最小化到托盘，不占用任务栏
- **开机自启动** - 可选开机自动运行
- **文件夹监控** - 监控指定文件夹中的压缩包
- **自动删除** - 解压完成后自动删除原压缩包
- **手动解压** - 内置解压功能，支持右键快速解压
- **多格式支持** - ZIP、RAR、7Z、TAR、GZ、BZ2、XZ

## 安装

### 方式一：直接运行 EXE（推荐）

下载 `AutoExtractCleaner.exe`，双击运行即可。

### 方式二：从源码打包

```bash
# 1. 安装 Python 3.8+
# 2. 进入项目目录
cd auto_extract_cleaner

# 3. 运行打包脚本
build.bat        # CMD
# 或
.\build.ps1     # PowerShell
```

## 使用方法

### 首次启动

1. 双击运行 `AutoExtractCleaner.exe`
2. 程序图标出现在系统托盘（屏幕右下角）
3. 右键点击托盘图标 → 选择「设置」
4. 在「监控文件夹」标签页添加要监控的文件夹
5. 点击「保存设置」

### 托盘菜单

| 选项 | 说明 |
|------|------|
| 开始/停止监控 | 切换监控状态 |
| 设置 | 打开设置窗口 |
| 手动解压 | 选择文件进行解压 |
| 开机自启 | 切换开机自动启动 |
| 退出 | 关闭程序 |

### 设置选项

| 选项 | 说明 |
|------|------|
| 监控文件夹 | 添加/移除要监控的文件夹 |
| 开机自动启动 | 系统启动时自动运行 |
| 启动时自动开始监控 | 程序启动后立即开始监控 |
| 解压后自动删除压缩包 | 解压完成后删除原文件 |
| 解压到同名子文件夹 | 创建与压缩包同名的文件夹 |
| 删除延迟 | 解压后等待 N 秒再删除 |

## 支持格式

| 格式 | 扩展名 |
|------|--------|
| ZIP | .zip |
| RAR | .rar |
| 7-Zip | .7z |
| TAR | .tar |
| GZIP | .gz, .tar.gz, .tgz |
| BZIP2 | .bz2, .tar.bz2 |
| XZ | .xz, .tar.xz |

## 注意事项

1. **RAR 格式**：需要系统安装 UnRAR 或 WinRAR
2. **权限**：首次设置开机自启需要管理员权限
3. **杀毒软件**：部分杀毒软件可能误报，请添加信任

## 文件位置

- 配置文件：`%APPDATA%\AutoExtractCleaner\config.json`
- 日志文件：`%APPDATA%\AutoExtractCleaner\app.log`

## 技术栈

- Python 3.8+
- pystray - 系统托盘
- watchdog - 文件监控
- py7zr - 7Z 解压
- rarfile - RAR 解压
- PyInstaller - 打包 EXE
